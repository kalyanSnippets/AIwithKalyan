# VIDEO-002 — thumbnail strategy

**Video:** Claude Code + REA cloned a Kanban app from one link in 20 minutes
**Working title:** Claude Code + REA Cloned This App in 20 Minutes (Can You Spot the Real One?)

Five distinct archetypes adapted to the research (see research/report.md). Shared rules: 1280x720, one focal point, at most 4 headline words, readable at 320 px, real evidence only, Kalyan's real face only, no Claude logo (no officially sourced file), bottom-right kept clear for the duration badge.

## Option A — Curiosity/Mystery (revision 0)

- **Story:** Two near-identical Kanban boards side by side: the real open-source app and the copy Claude Code + REA built from one link. The viewer is asked to pick.
- **Curiosity trigger:** They look the same — which one did the AI make? The answer is in the video (5:04 reveal).
- **Composition and subject positions:** Two equal tilted panels across the top two-thirds with a ? badge on each; one-line headline underneath, centred. No face, so the pair is the single focal point.
- **Main image / genuine evidence:** assets/evidence/wekan_crop.png and rea_crop.png — the same stills used in the video's side-by-side reveal, from Kalyan's screen recording 114559.
- **Background:** Ink with a soft coral glow; nothing generated.
- **Typography:** Inter Display Black 118 px, white with REAL in coral. Layers: "?" (82px), "?" (82px), "WHICH IS REAL?" (124px)
- **Colours, contrast, lighting:** Ink, coral, white; the boards bring orange/green which echo the coral.
- **Canva instructions:** Panels baked as separate image layers; ? badges as shapes + native text; headline native text. (plan: `studio canva-plan VIDEO-002 A`)
- **Image-generation prompts:**
  - none
- **Why it could work:**
  - vidIQ penalised a reference for an unclear comparison — this makes the side-by-side the whole thumbnail
  - Similar-thumbnail search found no REA 'spot the real one' thumbnails
  - Mirrors the title's question exactly
- **Risks and weaknesses:**
  - No face: may feel less personal on a tiny channel
  - At 320 px the boards read as 'two similar screens', not details — that is the point

## Option B — Face + Emotion (revision 0)

- **Story:** Kalyan, genuinely engaged, next to the REA Board that Claude Code built from a single link.
- **Curiosity trigger:** What could one link possibly produce? A full working board — how?
- **Composition and subject positions:** Board panel left with coral frame, tilted; Kalyan right with direct eye contact; headline across the top-left.
- **Main image / genuine evidence:** assets/evidence/rea_wide.png (REA Board, Kalyan's recording); face b128 from 4K camera original PXL_20261030_080129730 at 2:08, graded like the video.
- **Background:** Ink with coral glow behind Kalyan.
- **Typography:** Inter Display Black 116 px; '1 LINK' white, '= THIS' coral. Layers: "1 LINK = THIS" (116px)
- **Colours, contrast, lighting:** Ink, coral, white; Kalyan's maroon shirt sits well on ink.
- **Canva instructions:** Face cutout separate layer; board separate; headline native text. (plan: `studio canva-plan VIDEO-002 B`)
- **Image-generation prompts:**
  - none
- **Why it could work:**
  - Natural expression (vidIQ penalised exaggerated faces on 2 of 4 references)
  - Concrete result instead of a logo
  - Face builds recognition for a new channel
- **Risks and weaknesses:**
  - '= THIS' needs the board to read as an app at small size

## Option C — Minimalist Tech (revision 0)

- **Story:** The hype number (400K GitHub stars) against Kalyan's honest, sceptical look, with the real result as proof underneath.
- **Curiosity trigger:** A tool with 400K stars — is it actually worth it? Kalyan tested it.
- **Composition and subject positions:** Big coral 400K + star top-left, WORTH IT? beneath, small tilted REA Board panel bottom-left; Kalyan right with a thoughtful expression.
- **Main image / genuine evidence:** 400K stars: the REA GitHub page in Kalyan's 28 Oct recording showed 399K (rounded as in the video). Board: assets/evidence/rea_crop.png. Face b173 from PXL_20261030_080129730 at 2:53.
- **Background:** Ink with coral glow.
- **Typography:** 400K in Inter Display Black 200 px coral; WORTH IT? 108 px white. Layers: "400K" (200px), "WORTH IT?" (112px)
- **Colours, contrast, lighting:** Ink, coral, white.
- **Canva instructions:** Face and board separate; star icon as Canva element; text native. (plan: `studio canva-plan VIDEO-002 C`)
- **Image-generation prompts:**
  - none
- **Why it could work:**
  - Matches the honest-review angle the channel stands for
  - Big single number reads at 320 px
  - Pairs with the highest-scoring title (97)
- **Risks and weaknesses:**
  - '400K' is approximate (399K on 28 Oct, ~412K later) — the video says 400,000, so it's consistent
  - Two text blocks + panel: watch clutter
